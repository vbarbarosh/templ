Create a self-contained HTML audio/video player with:

* A fancy UI with light and dark themes.
* A media library that supports adding files from the device.
* Support for dropping individual files or entire folders into the page.
* Playback for any browser-supported media format, including MP4 and WebM.
* A playlist with drag-and-drop reordering and smooth animations.
* Drag-and-drop reordering should be implemented immediately while song is dragged.
* Highlighting for the currently active item.
* Single-click playback from the playlist.
* Visual display for video files.
* Audio visualizations for audio files.
* A choice of multiple visualization modes for audio files.
* For video files, allow switching between the original video track and audio visualization modes.
* Window-wide drag-and-drop support, ignoring drag events that originate inside the page.
* A button for adding media files.
